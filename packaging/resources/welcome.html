PDF Slim

This installer adds two macOS Finder Services for compressing PDFs:

  • PDF Slim - Light (Print, 300dpi) - around 89% size reduction, archival quality
  • PDF Slim - Medium (eBook, 150dpi) - around 94% size reduction, sweet spot

After install, right-click any PDF in Finder and choose Services to use them. The compressed file appears alongside the original; the original is never modified.

Requires Ghostscript. The installer will refuse to proceed if 'gs' is not on PATH. Install it first by visiting https://pages.uoregon.edu/koch/ and downloading the latest Ghostscript-X.Y.Z.pkg (signed and notarized; maintained by Richard Koch as part of MacTeX). Developers: 'brew install ghostscript' also works.
